# Third-party data

`data/deadlines.json` includes data copied from these open-source projects.
Both use the MIT License, which allows reuse as long as this notice is kept.

| Data | Project | Licence |
|---|---|---|
| Summer schools | [awesome-mlss](https://github.com/sshkhr/awesome-mlss) (`site/_data/summerschools.yml`) | MIT |
| Community talks (calls for talks at Python events) | [Python Deadlines](https://github.com/jesperdramsch/python-deadlines) (`_data/conferences.yml`) | MIT |

Conference deadlines also come from the [Papers with Code AI deadlines](https://paperswithcode.co/ai-deadlines)
list kept by Hugging Face, and from the public [OpenReview](https://openreview.net) API.
